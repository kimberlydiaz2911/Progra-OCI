Redefinicion de metodos heredados


Una clase deruvada puede declarar un metodo con el mismo nombre y mismos parameetros que 
uno de la base, este metodo nuevo reemplaza al de la base para los objetos de la 
clase derivada, en un proceso llamado redefinicion 


class Gerente : public Empleado{ 

public: 
    double bono; 

    Gerente (string nombre, double salario, double bono) 
    : Empleado (nombre, salario){
    this -> bono = bono; 

    }

    void pagar() {

        cout << nombre << "recibe" << salario << '\n';

    }
};
